🚀 Getting Started

Option 1: Quick Start (Recommended)

Clone the repository:
   bash
   git clone https://github.com/YOUR_USERNAME/cardiop-website.git
   cd cardiop-website
   
Open index.html in any modern browser:
   bash
   # macOS
   open index.html
   
   # Windows
   start index.html
   
   # Linux
   xdg-open index.html
   
That's it! No installation, no dependencies.

Option 2: Local Development Server

For a better development experience:
bash
Using Python
python -m http.server 8000

Using Node.js (npx)
npx serve .

Using PHP
php -S localhost:8000

Then visit http://localhost:8000

🌐 Deploy to GitHub Pages

Push your code to GitHub:
   bash
   git init
   git add .
   git commit -m "Initial commit: CardioP website"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/cardiop-website.git
   git push -u origin main
   
On GitHub, go to Settings → Pages

Under Source, select:
   - Branch: main
   - Folder: / (root)

Click Save

Your site will be live at:
   
   https://DynamicLiz.github.io/cardio-p/
